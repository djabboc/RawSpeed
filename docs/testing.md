最终集成记录：`artifacts/integration-results.json`，包含来源SHA256、逐阶段耗时、色彩标记及输出目录。本次所有源文件前后SHA相同；无损PNG逐字节回环，JPEG误差、ICC、方向和非覆盖语义均通过。测试进程峰值工作集约1.44GiB，包含多次完整解码、渲染、回读与native缓存，不是单次预览内存或全进程硬上限。

降噪记录和裁片：`artifacts/denoise/20261016-011803-553/`。NEF亮度70/色彩85/细节50，1600px算法预热中位50.7ms，原尺寸394.4ms；暗部色度高通RMS 8.249→0.871、亮度10.291→6.136。真实照片没有干净真值，这些是局部噪声代理指标，不能当画质分数。目视对照可见彩噪大幅减少，也存在残余亮度斑点与软化。详见 [降噪与性能](denoise-and-performance.md)。

## WPF与桌面边界

UiProbe使用实际App.xaml/MainWindow.xaml，在STA Dispatcher中测量、布局并通过RenderTargetBitmap输出图像；没有调用Window.Show。`artifacts/ui/`中包括编辑、最小布局、构图、降噪、LUT、EXIF、左右对比和曲线图，绑定警告为零。导出和快捷键窗口的离屏图位于 `artifacts/export-ui/`。这些是控件渲染图，**不是系统桌面截图**。

本机隔离构建的真实窗口已通过可访问性接口读取，实际键盘3设置星级成功。Windows桌面截图接口仍报 `FrameArrived timed out`，鼠标操作需要的可靠坐标无法取得。因此自由拖裁框、曲线加点拖动、分隔条拖动和系统保存对话框提交的真实鼠标验收仍未完整完成。相应数学、控件绑定和文件写出路径有自动测试，但不能替代完整桌面操作验收。

尚未进行多显示器/高DPI/触控、持续数小时的内存压力、数万张图库、更多相机型号或与DxO/Adobe的同图盲测。Native调用取消只保证结束后丢弃结果，不保证固定毫秒响应；当前8bit编辑不能据16bit容器导出测试宣称全程16bit质量。

桌面补充回归：通过真实滑条把曝光0改为1，预览更新；实际Ctrl+Z后曝光回0、重做可用。修复中文输入法对字母快捷键的拦截后，实际C成功切换构图页；可访问性滑条将裁框宽度改为70%，无需确认按钮。数字编辑控件的直接输入、Enter提交、失焦提交、非法输入与范围收敛另有16项导出/控件专项套件中的回归。桌面可访问性快照有延迟，因此状态变化均重新观察后确认。

## 2026-10-17 修复回归

Windows 10 x64、SDK 9.0.317、运行时 9.0.19、12 逻辑处理器。锁定依赖还原、Debug 与 Release 的 `-warnaserror` 构建均通过。执行 `./scripts/Test.ps1 -WithSamples` 后，新增状态栏检查另行运行 UiProbe，最终通过 Core 21、App 25、Catalog 6、Export 16、UiProbe 29、Integration 8，共 105 个 C# 场景，加 3 个打包脚本场景共 108 项检查。

- 配方回归：保存后关闭实例、删除生成缓存、迁移预设安装目录，再打开保持像素与强度；覆盖 v1 迁移、缺源/源变更、撤销/重做以及 UTF-8/UTF-16 BOM Cube。缺失来源不会在再次保存时被删除。
- 导入回归：1,024 个生成文件及重复路径，验证后台扫描、首张提前选中、批次间 Dispatcher 响应、评级恢复、集合索引更新、取消重试、新任务替代与关闭取消。实际 XAML 状态栏绑定和最小 1080×720 布局通过离屏检查。
- 打包脚本使用隔离的生成仓库和模拟编译输出，验证默认输出不继承本地预设或旧 DLL、失败保留原输出、拒绝不安全目标路径。本轮没有制作或上传发行包。
- JPG、NEF、ORF 样片的原文件 SHA-256 前后相同。结果仍写入忽略的 `artifacts/integration-results.json`；本轮集成测试的性能数据不直接替代上方不同硬件的历史记录。

真实 Debug 窗口已启动并读取可访问性树；桌面截图仍返回 `FrameArrived timed out`，点击接口报告 `coordinate input geometry is unavailable`，本轮未完成真实鼠标导入验收。窗口启动检查、导入模型测试及离屏控件检查分别记录，不视为完整桌面操作验收。

GitHub CI 仅执行锁定还原、编译和生成夹具测试；不打包、不上传二进制、不创建 Release。普通克隆不含用户样片，因此 CI 不执行真实样片集成测试。本地编译与调试步骤见 [开发文档](development.md)。
