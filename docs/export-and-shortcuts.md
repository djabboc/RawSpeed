# 导出规格与快捷键

## 导出

导出窗口先收集并验证设置，再选择新的目标文件名。取消设置窗口或文件选择器都不会启动导出。原图和已经存在的目标文件不会被覆盖；编码完成后才将同目录临时文件原子移动为最终文件。

| 设置 | 支持范围与行为 |
| --- | --- |
| JPEG | 品质 1–100，默认 92；可选渐进式编码，默认关闭；优化 Huffman 编码默认开启；8 位；透明像素合成到白色 |
| PNG | 无损，压缩级别 0–9，默认 2；8 位或 16 位 RGBA；压缩级别不会改变画质 |
| TIFF | 8 位或 16 位；LZW（默认）、ZIP 或不压缩；保留透明度 |
| 原始尺寸 | 使用编辑后的图像尺寸，已经包含裁切和旋转 |
| 指定长边 | 按原图比例缩放到指定长边 |
| 指定宽高 | 默认等比适合指定范围；取消“保持比例”后精确输出该宽高，可能拉伸图像 |
| 允许放大 | 默认关闭。关闭时最终尺寸不会超出源图的宽高范围；底部摘要显示实际输出尺寸 |
| 尺寸上限 | 每边 60,000 像素，最大 1 亿像素；窗口输入必须是正整数 |
| DPI | 72–1200，默认 300；仅写入打印分辨率，不改变像素数 |
| 色彩空间 | sRGB（默认）或 Adobe RGB (1998)，嵌入对应 ICC / 标准颜色声明 |
| 拍摄信息 | 不保留（默认）、常用拍摄参数不含 GPS、常用拍摄参数加 GPS |

`ImageFileService.ExportAsync` 的新重载接收不可变 `ExportOptions`。旧的 `quality` 重载继续兼容，并从目标扩展名推断格式。新重载要求扩展名与 `Format` 一致。`ResolveDimensions` 可在编码前取得确切尺寸；API 的 `Dimensions` 模式允许宽或高单独留空/设为 0，窗口则要求宽高都填写。API 在不允许放大时按同一倍率缩小请求范围，不单独裁掉某一个尺寸。

### 色彩与精度

输入是已经编辑的、方向正确的 **sRGB RGBA8**。内部在 Q16 精度执行重采样，并通过 Little CMS 的高精度转换生成 Adobe RGB 像素；转换后再按输出位深编码。Adobe RGB 会实际转换像素值，不是仅替换 ICC 标签。JPEG / TIFF 写入 ICC；sRGB PNG 可以用等价的 sRGB/gAMA 区块表示颜色声明。

16 位 PNG / TIFF 是从当前 8 位编辑结果生成的文件。它可保留此次重采样和色彩转换的计算结果，但不会恢复 RAW 源文件在进入 8 位编辑缓冲区前已经丢失的精度或高光。当前版本不提供场景线性、16 位 RAW 编辑链路，也不提供 CMYK、自定义 ICC、软打样或输出锐化。DPI 元数据只控制打印尺寸。

### 元数据保留规则

“常用拍摄参数”采用白名单，不等于复制源文件的全部 EXIF。JPEG 的可读 EXIF profile 会先过滤；NEF / ORF 在 LibRaw 不返回源 EXIF profile 时，由 MetadataExtractor 从标准 TIFF IFD 读取，再映射受支持字段。不会把 LibRaw 合成的默认零经纬度写成实际位置。

允许保留的标准字段（源文件存在且解码器可读时）：

- 相机制造商与型号；镜头制造商、型号与规格；Artist 与 Copyright。
- 拍摄 / 数字化日期、相应时间偏移和秒的小数部分。
- 曝光时间、F 数、曝光程序、ISO / 感光度类型 / 推荐曝光指数。
- 快门、光圈、亮度、曝光补偿、最大光圈的 APEX 值；主体距离。
- 测光、光源、闪光、焦距与 35 mm 等效焦距、曝光模式、白平衡、场景类型。

RAW 的直接映射覆盖相机、镜头名称、作者版权、拍摄日期及秒的小数部分、曝光 / ISO / 光圈 / 快门 / 补偿 / 测光 / 闪光 / 焦距等常用字段；RAW 时间偏移、镜头规格及推荐曝光指数当前未映射，缺失字段不会猜测。厂商 MakerNotes、机身和镜头序列号、旧缩略图、任意用户注释、旧图像存储布局、XMP / IPTC 与编辑历史不复制。

选择 GPS 后才允许保留：纬度 / 经度及方向、海拔及参考面、GPS 日期与时间、图像方向及参考；JPEG profile 还允许 GPSVersionID。RAW 只映射实际存在的标准 GPS 字段，不生成缺失坐标。

输出始终重新写入 Orientation=1、实际宽高、DPI、颜色空间标识及 Software=RawSpeed，避免裁切或旋转之后再次应用旧方向、旧尺寸。元数据为“不保留”时，不复制拍摄字段；编码格式必需的尺寸 / 色彩结构仍然存在。

## 快捷键与鼠标

“快捷键与鼠标”窗口支持编辑每项操作的一个或多个输入方式；多个方式使用英文分号 `;` 分隔，留空可停用该项。保存前检查所有操作之间的冲突，取消不改变当前设置。

| 操作 | 默认输入 |
| --- | --- |
| 打开 / 保存配方 / 导出 | `Ctrl+O` / `Ctrl+S` / `Ctrl+E` |
| 撤销 / 重做 | `Ctrl+Z` / `Ctrl+Y;Ctrl+Shift+Z` |
| 原图对比 / 切换对比方式 | `B` / `Y` |
| 构图 / 适合窗口 / 100% | `C` / `F` / `D` |
| 放大 | `WheelUp;Add;Ctrl+OemPlus` |
| 缩小 | `WheelDown;Subtract;Ctrl+OemMinus` |
| 上一张 / 下一张 | `Left` / `Right` |
| 清除评分 | `D0;NumPad0` |
| 1–5 星 | `D1;NumPad1` 至 `D5;NumPad5` |

组合键修饰符支持 `Ctrl`（也接受 `Control`）、`Shift`、`Alt`、`Win`（也接受 `Windows`），例如 `Ctrl+Shift+E` 或 `Ctrl+WheelUp`。保存时会统一大小写与顺序，并去除同一操作中重复的方式。数字 `0`–`9` 也可直接输入，保存后为 `D0`–`D9`；`Add` / `Subtract` 是数字小键盘加减号，主键盘使用 `OemPlus` / `OemMinus`。`Plus` / `Minus` 是对应的别名。

修饰符需要完全匹配：`Ctrl+O` 不会响应 `Ctrl+Shift+O`。裸修饰键、无效键名、重复修饰符和 `Esc` 不可配置；`Esc` 保留用于退出当前工具。数字编辑框、文本输入和曲线键盘编辑由主窗口优先处理，避免输入数字时触发评分。滚轮手势只由图像视口分发，设置面板的正常滚动不会触发缩放。

## 偏好文件

默认路径为 `%LOCALAPPDATA%\RawSpeed\preferences.json`。保存内容包括快捷键字典、照片栏宽度、工具栏宽度、直方图高度与缩略图尺寸。窗口布局由主窗口关闭时保存；快捷键在明确点击“保存快捷键”后保存。

偏好文件版本为 1，最大 256 KiB。读取失败、内容损坏、未知版本、快捷键冲突或非法布局数值会回退默认值，并由 `PreferencesStore.LastLoadError` 提供诊断；加载本身不改写坏文件。保存先验证，再通过同目录临时文件原子替换旧偏好文件。当前没有跨设备同步、按工作区选择不同快捷键配置或导出规格预设持久化。
